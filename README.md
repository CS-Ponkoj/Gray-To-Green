# Gray to Green: Community Environmental Monitoring

> A web and mobile application concept for comparing trees with local population and reporting garbage locations so communities can coordinate cleanup.

## Overview

Gray to Green brings environmental observations, image-preprocessing work, application artifacts, and project documentation into one repository.

## Motivation

Visible environmental problems are easier to address when residents can document them, share locations, and connect observations with local context.

## Goal and Research Question

**Goal:** Organize environmental observations into an accessible web and mobile workflow.

**Question:** How can a community-facing application combine tree-to-person indicators with citizen-reported garbage locations?

## Technical Approach

1. Collect and preprocess environmental imagery.
2. Package web and Android application artifacts.
3. Document the tree-to-person and garbage-reporting concepts.
4. Preserve a demonstration PDF and supporting documentation.

## Tech Stack

- Web and mobile application assets
- Image-preprocessing workflow
- Android application archive
- PDF and DOCX documentation

## Results and Deliverables

- The repository includes an application demonstration, project documentation, preprocessing assets, NASA-related files, and an Android archive.
- No deployment, adoption, or model-accuracy result is recorded, so none is claimed.
